# fnOS 应用安全审查清单

## 1. 权限与进程

- [ ] 默认 `run-as=package`。
- [ ] `join-groups` 每一项都有明确硬件/资源理由。
- [ ] Root 只用于无法替代的特权准备任务。
- [ ] 长期网络服务不以 root 运行，或启动后立即降权。
- [ ] 服务仅监听必要的端口或 Unix Socket。
- [ ] 不把内部管理接口绑定到所有网卡，除非有明确认证和业务需要。

阻断问题示例：Web 服务以 root 运行并直接处理用户可控路径或命令参数。

## 2. API Scope 与 Token

- [ ] `config/resource` 仅声明实际调用的 `api-scope`。
- [ ] 后端 API 只通过 `/var/run/trim_open_gateway_apiscope.socket` 调用。
- [ ] 浏览器代码不调用 `/api/v1/trimapp`。
- [ ] `TRIM_API_TOKEN` 每次从环境读取。
- [ ] Token 不写入数据库、文件、缓存、日志、错误信息、URL、前端 bundle。
- [ ] 后端对允许调用的 `req` 使用白名单，不接受前端任意透传。
- [ ] `401`、`403` 分别按 Token 与 Scope 排查，不把 Token 输出到诊断信息。

## 3. 用户身份

- [ ] 统一网关请求使用 `X-Trim-Userid`、`X-Trim-Isadmin`、`X-Trim-Username`。
- [ ] 不信任请求体、查询参数、Cookie、自定义 Header 或 WebSocket 消息里的 UID/管理员标记。
- [ ] 管理接口显式检查管理员身份。
- [ ] 每条业务记录与当前用户或明确共享策略绑定。
- [ ] WebSocket 建连时绑定网关 UID，后续消息不允许切换身份。
- [ ] 网关登录态与应用业务权限分开检查。

## 4. 文件授权与 ACL

- [ ] 管理员共享授权仅用于全局固定目录。
- [ ] 用户个人授权按当前可信 UID 查询。
- [ ] 文件授权结果不会误当作可查询目录授权。
- [ ] 返回列表、预览、下载前检查 `readable`。
- [ ] 写入前检查 `writable`。
- [ ] 删除前检查 `deletable`。
- [ ] ACL 为 false、路径不存在或检查失败时默认拒绝。
- [ ] “应用拥有访问路径”不被误解为“所有登录用户都有访问权”。

## 5. 路径安全

仅检查字符串是否包含 `..` 不够。推荐流程：

1. 拒绝空路径、NUL 字节、异常编码和不支持的路径类型。
2. 对允许根目录和目标路径进行规范化/真实路径解析。
3. 确保目标路径等于允许根，或位于允许根目录之下。
4. 处理符号链接，防止从允许目录逃逸。
5. 对写入目标的父目录执行同样验证。
6. 再检查当前用户 ACL。
7. 文件类型、大小、数量和扩展名仅作为附加限制，不替代路径边界。

伪代码：

```text
allowed = realpath(authorized_root)
target  = realpath(candidate)
require target == allowed OR target startsWith(allowed + pathSeparator)
require user ACL permits requested operation
```

- [ ] 不将路径直接拼到 shell 命令。
- [ ] 必须调用外部程序时，使用参数数组，不使用 `sh -c` 拼接。
- [ ] 不跟随用户可控符号链接越过授权根。
- [ ] 不提供密钥、数据库、配置、私有日志目录。
- [ ] 页面展示路径时使用语义路径，而非直接泄露内部 `/vol...` 路径。

## 6. CGI 与网关

### CGI

- [ ] 仅处理轻量普通 HTTP 请求。
- [ ] 不用于 WebSocket、长耗时、高流量或复杂 API。
- [ ] 正确返回状态码和 MIME。
- [ ] 路径映射执行真实路径边界检查。
- [ ] 不执行请求参数。

### 统一网关

- [ ] `gatewayPrefix` 使用稳定 `/app/{appname}` 路径。
- [ ] `gatewaySocket` 只含文件名，Socket 位于 `TRIM_APPDEST`。
- [ ] 服务启动前移除陈旧 Socket；停止时清理。
- [ ] Socket 文件权限只允许必要主体访问。
- [ ] HTTP 和 WebSocket 路由都位于声明前缀。
- [ ] 公开 OAuth/回调路由极窄，只允许必要方法和参数。
- [ ] 不把 `protocol`/`port` 当作网关路由条件。

## 7. 授权回调与前端

- [ ] `manifest` 有 `micro_app=true`。
- [ ] 独立浏览器授权由用户点击触发。
- [ ] `state` 使用不可预测值并在回调校验。
- [ ] `redirectUri` 尽量为统一网关同域路径。
- [ ] 回调 `postMessage` 使用精确 `window.location.origin`。
- [ ] 原页面检查 `event.origin` 和消息类型。
- [ ] 不向回调 URL 放敏感数据。
- [ ] 原页面保留手动刷新授权状态入口。
- [ ] `$on` 仅在受支持 Web 宿主使用。
- [ ] 外部 URL 经过协议白名单，通常只允许 `https:`；避免 `javascript:`、`data:` 等危险协议。

## 8. 向导、配置与密钥

- [ ] 只收集必要配置。
- [ ] 密钥使用 `password` 字段，且生命周期脚本不回显。
- [ ] `config.env`、`.env`、Token、密码不提交仓库。
- [ ] 配置文件权限限制到应用用户。
- [ ] 日志不记录密码、Token、访问密钥和完整敏感文件内容。
- [ ] 配置变更脚本可重复执行，失败不会留下半更新状态。

## 9. 数据与升级

- [ ] 配置放 `TRIM_PKGETC`，持久数据放 `TRIM_PKGVAR`/`TRIM_PKGHOME`。
- [ ] 临时文件放 `TRIM_PKGTMP`。
- [ ] 升级迁移有版本判断、备份或事务策略。
- [ ] 升级失败可恢复，不留下新旧格式混用。
- [ ] 卸载只删除应用拥有且用户明确选择删除的数据。
- [ ] 外部共享目录默认保留，除非用户明确确认。
- [ ] 数据库和中间件使用应用命名空间，避免跨应用冲突。

## 10. 依赖与供应链

- [ ] `platform=all` 只用于真正架构无关的包。
- [ ] 运行时和中间件只声明直接需要项。
- [ ] 第三方依赖版本可复现，来源可信。
- [ ] 不在安装脚本中无校验下载并执行远程脚本。
- [ ] 外部服务不可用、磁盘满、内存不足时可控失败。
- [ ] Docker 镜像支持目标架构并有固定版本或摘要策略。

## 11. 日志与错误

- [ ] 生命周期失败先写可执行的用户提示到 `TRIM_TEMP_LOGFILE`。
- [ ] 服务日志包含时间、级别、reqId，但不含秘密。
- [ ] 对用户隐藏内部堆栈、Socket 路径以外的敏感实现信息。
- [ ] 认证/授权错误返回明确但不过度暴露的信息。
- [ ] 默认拒绝未知 `req`、未知操作和无法识别的文件类型。

## 12. 审查输出模板

```text
严重度：阻断 / 高 / 中 / 低
位置：path/to/file:line
问题：一句话描述
影响：可导致什么
证据：相关配置或代码行为
修复：最小、具体、可验证的修改
验证：修复后如何测试
```
